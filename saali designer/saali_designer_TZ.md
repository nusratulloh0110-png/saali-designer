## 🎨 ДИЗАЙН-КОНЦЕПЦИЯ

### Визуальный стиль
- **Направление:** Luxury Ethno — роскошный этнический, восточная рафинированность
- **Культурная база:** Традиционное узбекское искусство — ислими (растительный орнамент), пахта (цветок хлопка), геометрические гирихи, мотивы медресе, архивольты арочных проёмов
- **Что ИСКЛЮЧЕНО:** Атлас и его паттерны — не использовать

### Цветовая палитра (строго по логотипу)
```
--color-primary:     #C4623A   /* Терракота / медь — главный акцент */
--color-secondary:   #3D4F6B   /* Тёмно-синий — текст, фоны */
--color-gold:        #C9A96E   /* Золото — декор, линии, иконки */
--color-cream:       #F5F0E8   /* Кремовый — основной фон */
--color-dark:        #1A1A2E   /* Почти чёрный — хедер, футер */
--color-white:       #FDFAF5   /* Тёплый белый — карточки */
```

### Типографика
```
Заголовки H1-H2:  "Playfair Display" (serif, элегантность)
Подзаголовки H3:  "Cormorant Garamond" (serif, утончённость)
Основной текст:   "Nunito" или "Mulish" (sans-serif, читаемость)
Акцентные слова:  "Playfair Display Italic"
Подключение:      Google Fonts CDN
```

### Декоративные элементы (SVG — встроенные)
1. **Верхний и нижний разделитель секций** — тонкая линия с центральным орнаментом пахта (хлопок)
2. **Фоновый паттерн Hero** — полупрозрачный геометрический гирих (opacity: 0.04), как watermark
3. **Угловые декоры карточек** — маленький угловой ислими-узор (SVG) в углах карточек
4. **Арка в About-секции** — декоративная мотивная арка (стиль порталов Самарканда) как обрамление фото
5. **Иконки** — кастомные SVG в этническом стиле (вместо стандартных)
6. **Divider между секциями** — волнистая или геометрическая SVG-полоса цвета --color-gold

### Анимации
- **Scroll-reveal:** секции появляются снизу вверх (IntersectionObserver, translateY + opacity)
- **Hero ornament:** фоновый паттерн медленно вращается (CSS keyframes, 120s, очень плавно)
- **Кнопки:** hover — сдвиг фона, ripple-эффект при клике, плавный scale(1.03)
- **Карточки каталога:** hover — подъём (translateY -8px), усиление тени, gold border появляется
- **Loader (прелоадер):** логотип saali.designer появляется с fade-in, затем исчезает (0.8s)
- **Cursor:** кастомный курсор — маленький орнамент пахта следует за мышью (только desktop)
- **Счётчики в статистике:** анимированный count-up при входе в видимость

## 🔌 ИНТЕГРАЦИЯ NETLIFY BLOBS

Каталог хранится в Netlify Blobs и обновляется через Telegram-бота.

### Структура товара

```json
{
  "id": 1,
  "name_ru": "Сумка с медальоном",
  "name_uz": "Medalyonli sumka",
  "category": "bags",
  "price": 320000,
  "old_price": 380000,
  "description_ru": "Описание на русском",
  "description_uz": "Описание на узбекском",
  "material": "Материал",
  "size": "22 x 18 см",
  "image_url": "https://example.com/image.jpg",
  "in_stock": true,
  "featured": true
}
```

### Получение данных

`catalog.js` сначала запрашивает `/.netlify/functions/catalog`. Функция читает товары из Netlify Blobs, а если хранилище временно недоступно, возвращает локальный fallback из `assets/data/products.json`.

### Управление через Telegram

`/add` запускает пошаговое добавление товара на русском языке. `/delete` показывает список товаров с ID и удаляет выбранный товар. `/delete 12` удаляет товар сразу по ID.

**Обработка ошибок:**
- Если функция каталога недоступна → сайт берет локальный fallback-файл.
- Если нет ни функции, ни fallback → показать сообщение "Каталог временно недоступен. Посмотрите наш Telegram-канал" + кнопка на @saalidesigner.
- Retry-кнопка остается в пустом состоянии каталога.

function renderProductCard(product, lang = 'ru') {
  const name = lang === 'ru' ? product.name_ru : product.name_uz;
  const desc = lang === 'ru' ? product.description_ru : product.description_uz;
  const price = new Intl.NumberFormat('uz-UZ').format(product.price);
  const oldPrice = product.old_price 
    ? `<span class="card__old-price">${new Intl.NumberFormat('uz-UZ').format(product.old_price)} сум</span>` 
    : '';
  const tgMessage = encodeURIComponent(`Здравствуйте! Хочу заказать: ${product.name_ru} (ID: ${product.id})`);
  
  return `
    <article class="product-card" data-category="${product.category}" data-id="${product.id}">
      <div class="product-card__image-wrap">
        <img src="${product.image_url}" alt="${name}" loading="lazy" class="product-card__image">
        <span class="product-card__badge">${getCategoryLabel(product.category, lang)}</span>
        <div class="product-card__corner product-card__corner--tl"></div>
        <div class="product-card__corner product-card__corner--tr"></div>
      </div>
      <div class="product-card__body">
        <h3 class="product-card__title">${name}</h3>
        <p class="product-card__desc">${desc}</p>
        <div class="product-card__price-row">
          <span class="product-card__price">${price} сум</span>
          ${oldPrice}
        </div>
        ${!product.in_stock ? '<span class="product-card__sold-out">Нет в наличии</span>' : ''}
        <a 
          href="https://t.me/svmlnn?text=${tgMessage}" 
          target="_blank" 
          rel="noopener noreferrer"
          class="btn btn--primary btn--full ${!product.in_stock ? 'btn--disabled' : ''}"
          ${!product.in_stock ? 'aria-disabled="true"' : ''}
        >
          <svg><!-- Telegram icon --></svg>
          Заказать в Telegram
        </a>
      </div>
    </article>
  `;
}
